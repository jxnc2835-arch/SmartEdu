📖 操作手册 v3.5 完整版

🚀 快速开始
1. 访问 http://服务器IP:3000/teacher.html 进入管理端
2. 默认管理员：admin / admin123（首次登录后建议修改密码）
3. 学生端地址：http://服务器IP:3000/student.html
4. 数据大屏：侧边栏底部「🖥️ 数据大屏」（适合投屏展示）
🛏️ 查寝管理（首页）
• 顶部统计：在寝/未归/请假人数 + 签到率 + 总人数（可切换班级）
• 实时动态：最新查寝/请假/签到记录，自动滚动更新
• 宿舍分布：按宿舍统计在寝/未归/请假人数及签到率
• 查寝签到记录：按班级 / 状态（在寝/未归/请假）/ 日期区间筛选，支持关键字搜索
• 📢 发布查寝任务、📥 导出、📄 导出报告、📱 推送未归
• 侧边栏「🖥️ 数据大屏」：投屏专用大屏看板
📝 请假管理
• 学生端提交请假（附证明材料）→ 教师端审批
• 点击「详情」查看附件图片、请假区间
• 点击「审批」选择批准/驳回，可填写审批意见
• 审批结果实时推送到学生端（WebSocket + 桌面通知）
• 📥 导出请假记录为 Excel
🏫 课程考勤
• 「➕ 创建签到」创建单次课程（含课程名称、时间、地点、班级）
• 「📋 批量导入课表」按规则批量生成
• 学生端选择课程 → 定位 → 签到（或📷扫码签到）
• 课堂出勤统计：按日期、课程筛选，展示到课/缺勤人数
• 📥 导出课堂签到记录
👥 学生管理
• 📋 批量导入：Excel 或 CSV，格式：姓名,性别,学号,宿舍,班级,年级,专业,电话
• 单条操作：编辑资料 / 重置密码（默认123456）/ 删除
• 🔑 批量重置密码：选择班级+宿舍，一键重置全部
• 🎓 班级限制：每班最多 40 人
• 人脸注册：上传学生照片，提取人脸特征用于签到验证
• 导入导出模板：点击「📥 下载模板」获取标准格式
🛏️ 宿舍管理
• 「➕ 添加宿舍」创建新宿舍（楼栋、房间、楼层、容纳人数、性别）
• 按楼栋 / 楼层 / 性别筛选
• 实时显示已住人数 / 空余床位
• 批量重置密码时可选宿舍范围
📈 统计分析
• 操行评分：基础100分，签到+1、缺勤-5、请假-1，可导出
• 班级月报：最近7/30天签到统计，含 AI 简报
• 宿舍评比：按宿舍统计平均签到率，高亮优秀/落后宿舍
• 重点关注：缺勤率高、请假频繁的学生自动标记
• 宿舍异常：全员未归宿舍监控
• 请假趋势：每日请假人数统计
• AI 风险预测：基于历史数据预测签到率、风险学生、请假趋势
👨‍💼 用户管理（仅限超级管理员）
• 添加 / 编辑 / 删除辅导员、班主任、院领导账号
• 角色权限：辅导员管理本班、班主任查看班级、院领导只读
• 每个用户可绑定多个管理班级（回车添加标签）
• 🔐 密码管理：选择用户 → 修改密码
• 🎨 主题色：支持6种主题色切换（科技蓝/翠冷/琥珀橙等）
🤖 AI 智能助手
• 智能问答：输入"今天谁没签到？""未归学生""预测签到率"等，自动查询+智能回答
• 支持9类意图：今日签到 / 未归 / 高风险 / 趋势预测 / 班级对比 / 请假 / 宿舍 / 课程 / 建议
• 人脸识别：学生一键拍照签到，自动提取128维人脸特征
• 数据预测：线性回归预测（签到率、风险学生、请假趋势）
• 连接大模型 API（支持智谱/DeepSeek/通义/OpenAI 等）生成专业分析
🎤 应急与位置验证（系统设置）
• 语音签到：网络差/摄像头故障时，学生说口令即可签到（Web Speech API）
• GPS 围栏：设置宿舍/教室地理围栏，超出范围自动拦截+告警
• 企业微信/钉钉：配置 Webhook 后异常自动推送（未归、围栏告警等）
• 发布公告：给学生端推送通知，WebSocket + 桌面通知双通道
📍 以上功能均位于「⚙️ 系统设置」页面
⚙️ 系统设置
• 系统日志：按日期/操作类型/级别查看所有操作记录
• 数据备份：导出数据库+照片的完整备份包
• 数据清除：按班级选择性清除签到记录
• 智能预警规则：设置缺勤次数/请假天数/连续未归阈值
• Webhook 通知：配置通用 Webhook 地址
• 操作提示：启动脚本 start.bat，停止脚本 stop.bat
⚡ 学生端离线签到：断网时签到数据本地保存（IndexedDB），联网自动同步
⚡ 扫码签到：学生端「📷 扫码签到」可扫码快速完成查寝/课堂签到

📋 批量导入课表

选择班级后，导入的课表将仅对该班级生效；留空则为所有班级共享
— 或手动输入 —
📌 格式说明：
每行格式：课程名,星期(1-7),开始时间,结束时间,地点
星期：1=周一，2=周二，…，7=周日
时间格式：HH:MM（如 08:00、14:30）
字段间用英文逗号分隔
✅ 示例：
测绘工程导论,1,08:00,09:40,测绘楼201
数字测图原理,3,10:00,11:40,测绘楼305
飞行技术基础,5,14:00,15:40,操场

📋 批量导入学生

— 或手动输入 —
📌 格式：
每行一个学生，字段用英文逗号分隔
顺序：姓名, 性别, 学号, 宿舍, 班级, 年级, 专业, 电话
⚠️ 每班最多 40 人，超过上限的班级将无法导入
✅ 示例：
张三,男,S202401,12栋301,241测绘,2024,测绘工程,13800138000
李四,女,S202402,12栋302,242测绘,2024,测绘工程,13800138001

# 学管 SmartEdu —— 老师 / 学生 使用指引（极简版）

> 本系统是学院学生智能管理系统（智能查寝为核心场景）。辅导员已在学院一台电脑上 24 小时开机运行，并通过内网穿透把系统发布到公网。
> **你只要有一台能上网的手机或电脑，打开链接、用账号登录即可，不用连校园 WiFi、不用装任何软件。**

---

## 一、怎么打开系统

1. 辅导员会发给你一个以 **`https://`** 开头的地址（形如 `https://xxxx.cpolar.io`）。
2. 用 **手机或电脑浏览器**（推荐 Chrome / Edge / 手机自带浏览器）打开这个地址。
3. 进入后根据你的身份，点对应入口：
   - 学生 → **学生端**
   - 老师 → **教师端**
   - 想看全院数据大屏 → **数据大屏**

> ⚠️ 必须用 **https** 开头的地址打开（不要手动改成 http），否则手机/电脑的摄像头权限会被浏览器拦截，人脸识别用不了。

---

## 二、学生怎么用（查寝 / 签到）

1. 打开地址后进入 **学生端**（`/student.html`）。
2. 用 **学号 + 密码** 登录（账号由辅导员/班主任发放）。
3. 到查寝或签到时间，点击「开始签到」：
   - 允许浏览器使用**摄像头**；
   - 把脸对准取景框，按提示**眨眨眼**完成活体检测；
   - 系统识别通过后即签到成功，页面会显示「签到成功」。
4. 若活体检测没通过，记录会标记「待复核」，由老师端人工确认，**不要重复刷脸**。
5. 可随时在「我的记录」里查看自己历史签到情况。

**常见问题**
- 打不开摄像头：检查是否用了 https 地址；手机需在浏览器弹窗里点「允许」摄像头权限。
- 识别慢/失败：光线明亮、正脸、摘掉遮挡物；网络差时稍等或切换 WiFi/流量。
- 忘记密码：联系辅导员重置。

---

## 三、老师怎么用（查看 / 管理）

1. 打开地址后进入 **教师端**（`/teacher.html`）。
2. 用 **教师账号 + 密码** 登录（由辅导员发放）。
3. 主要功能：
   - **查寝记录**：实时查看本班/本宿舍学生签到状态，未签到、活体未通过的会**红底 + ⚠ 标红**提醒。
   - **学生管理**：查看学生名单、学号等信息。
   - **数据统计**：出勤率、在寝率趋势等（含 AI 预测）。
   - **数据大屏**：点「数据大屏」（`/dashboard.html`）看全院可视化大屏，适合投屏开会。
4. 对标记「待复核」的记录，老师可人工确认是否属实。

**常见问题**
- 看不到某学生：确认该学生已用正确学号登录并签到；或联系辅导员核对名单。
- 大屏投屏：用电脑浏览器全屏打开数据大屏地址即可。

---

## 四、注意事项

- **账号安全**：学号/教师账号密码请勿外泄；首次登录后建议修改初始密码。
- **隐私**：系统含学生人脸等敏感信息，仅限本院师生在授权范围内使用，不要把登录地址随意转发到公开群。
- **网络**：手机用流量、家里宽带、校园 WiFi 都能访问；如打不开，先确认地址是否为最新的 https 链接（免费版地址偶尔会变，以辅导员最新发送为准）。
- **校内直连 IP**：如果辅导员发的是 `http://192.168.x.x:3100` 这种校内地址（仅限校园网），该 IP 可能因路由器重新分配而变化，打不开时请向辅导员确认最新 IP；更稳的方式是统一使用 cpolar 公网 https 地址（不随内网 IP 变化）。
- **服务时间**：系统由学院电脑 24 小时运行；极少见的服务维护期间可能短暂打不开，稍后重试即可。

---

## 五、联系 / 报障

遇到打不开、登录失败、识别异常等问题，第一时间联系 **辅导员** 或系统管理员，并截图报错页面，便于快速排查。

# 学管 SmartEdu —— 学院内部部署与运维说明（辅导员专用 · 零成本 · 数据不出院）

> 适用场景：仅供**本学院辅导员**日常使用，系统部署在**学院机房/办公室一台常开电脑**上。
> 核心目标：① 免 bat、开机自启、崩溃自拉；② 辅导员**校内**连校园网即用；③ 辅导员**校外/回家**也能用，但数据**全程留院内、不上公网**。
> 成本：0 元/月（不买云、不暴露公网）。

---

## 一、方案总览

```
[辅导员·校内电脑/手机] ──校园网/WiFi──► [学院常开电脑 192.168.x.x:3100]
[辅导员·校外/在家]   ──Tailscale 加密通道──► [学院常开电脑 :3100]
```

- **院内**：辅导员连校园网，用服务器的内网 IP 直接访问。
- **院外**：装 Tailscale（免费私有组网），辅导员设备与学院电脑组同一个加密网络，数据走 WireGuard 加密，**不进公网、不开任何公网端口**。
- **守护**：`server.js` 由 PM2 托管（开机自启 + 崩溃自拉）；Tailscale 自身是系统服务，也开机自启。
- **为什么不用 Cloudflare 公开隧道/公有云**：那会把学生人脸、签到等敏感数据暴露到公网或第三方云，院内自用既没必要也增加合规风险。

---

## 二、准备常开电脑

1. 选一台**不关机**的电脑（机房/辅导员办公室），建议接网线。
2. **固定内网 IP**（关键）：在电脑的网络设置里把 IPv4 设为静态 IP，或在学院路由器给该机 MAC 绑定固定 IP，避免 IP 变化后辅导员找不到服务。例如固定为 `192.168.1.50`。
3. 装 **Node.js 22.x LTS**（https://nodejs.org ，含 npm，一路默认）。
4. 把整个 `学管 SmartEdu` 项目文件夹拷到该机（含 `config/data.db` 业务数据、`ecosystem.claw.config.js` 等）。

---

## 三、PM2 自启服务（消 bat + 开机自启）

以**管理员 PowerShell** 运行：

```powershell
npm install -g pm2 pm2-windows-startup
cd D:\学管SmartEdu
pm2 start ecosystem.claw.config.js     # 拉起 server（3100 / 3543）
pm2 save                              # 固化进程列表
pm2-startup install                   # 注册 Windows 服务：开机自动 resurrect
```

验证：重启这台电脑，浏览器开 `http://localhost:3100` 仍可用，即配置成功。
（注：`ecosystem.claw.config.js` 已设为 `interpreter: 'node'` 走 PATH，换机器无需改路径。）

---

## 四、院内访问（辅导员在校园网/WiFi 内）

1. 在服务器上 `ipconfig` 查 IPv4 地址（如 `192.168.1.50`）。
2. 辅导员在**同一校园网**下的浏览器打开：
   ```
   http://192.168.1.50:3100
   ```
   学生端 `/student.html`、教师端 `/teacher.html`、数据大屏 `/dashboard.html`、AI 问答均在同端口下。
3. 建议：把该内网 IP 记给辅导员，或在学院内网 DNS 解析一个好记名字（如 `smartedu`）。

---

## 五、院外访问：Tailscale 私有组网（不上公网）

### 5.1 管理员（你）操作
1. 注册免费 Tailscale 账号：https://tailscale.com （免费额度足够一个学院规模，以官网当前政策为准）。
2. 学院常开电脑安装 Tailscale Windows 客户端，登录你的账号，保持开机。
3. 在 Tailscale 后台**邀请辅导员**加入同一 tailnet（可发邀请链接，辅导员用自己的账号接受，或用节点共享）。

### 5.2 辅导员操作
1. 手机/电脑装 Tailscale App，登录被邀请的账号，连上网络。
2. 直接用学院电脑的 **Tailscale IP**（形如 `100.x.x.x`）或 **MagicDNS 主机名**访问：
   ```
   http://100.x.x.x:3100
   ```
   或 `http://<你的主机名>:3100`。在家/在外也能进，流量经 WireGuard 加密，不暴露公网。

### 5.3 安全与防火墙
- **无需**在学院路由器或防火墙开放 3100 的任何公网入站规则——Tailscale 走的是 UDP 打洞/中继，设备间直连加密。
- 只有被你邀请的设备能进 tailnet，外界扫不到后台。

---

## 六、HTTPS（可选）

- 院内/院内用 `http` 即可（内网）。
- 若想让辅导员用 `https` 访问（消除浏览器警告、更正式）：Tailscale 后台可对该设备开启 **HTTPS（MagicDNS + 免费证书）**，或用其 `serve` 功能反代到 `localhost:3100`。非强制。

---

## 七、安全提醒

- admin 强口令已设（`gWQBdNDDq8xD8B&$`），**上线前请在后台改一次**为自己记得的强口令。
- 因不走公网，不用对外开端口；仅保证院内 LAN 可达 + Tailscale 通道正常。
- 学生人脸/签到属敏感信息，本方案数据**全程留在学院电脑**，符合院内自用合规要求。

## 八、日常运维

```powershell
pm2 status                 # 看 smartedu-claw 是否 online
pm2 logs smartedu-claw      # 看服务日志
pm2 restart smartedu-claw   # 改完配置/代码后重启
pm2 stop smartedu-claw      # 临时停（开机仍会自启）
pm2 unstartup              # 取消开机自启（需管理员）
```

数据备份（可选，防硬盘坏）：
```powershell
copy D:\学管SmartEdu\config\data.db D:\备份\data-%date:~0,10%.db
```

- 本方案 = **路线2 的「PM2 自启」部分** + **Tailscale 私有组网替代公开隧道**。

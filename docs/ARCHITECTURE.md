## 核心设计模式

### 1. 工厂函数模式
```javascript
// 每个路由模块导出 init() 工厂函数
const { init: initAuthRoutes } = require('./routes/auth');
const authRouter = initAuthRoutes({ db, scheduleSave, authMiddleware, ... });
app.use(authRouter);
```

### 2. 依赖注入
```javascript
// 通过 opts 对象传递共享资源
function init(opts) {
  const { db, scheduleSave, authMiddleware, ... } = opts;
  // 模块内部使用注入的依赖
}
```

### 3. 前后端分离
- **前端**: 原生 HTML5/CSS3/JS，无框架依赖
- **后端**: Express.js REST API + WebSocket 实时推送
- **通信**: JSON over HTTP/WebSocket

## 扩展点

1. **新增路由模块**: 在 `routes/` 创建新文件，实现 `init()` 工厂函数
2. **自定义中间件**: 在 `middleware/` 添加，如速率限制、CORS
3. **AI 模型扩展**: 在 `utils/` 添加新的预测模型 (如 Prophet, XGBoost)
4. **通知渠道**: 在 `routes/notify.js` 添加新的 webhook 类型

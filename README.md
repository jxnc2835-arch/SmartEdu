## 🎯 系统概述

学生管理系统是一款面向高校辅导员的 **AI 智能化查寝管理平台**，集成了人脸识别、数据预测、智能助手等先进技术，实现了从传统查寝到 AI 智慧管理的升级。

### 核心优势
| 维度 | 传统查寝系统 | 本系统 |
|------|------------|--------|
| 身份验证 | 密码/扫码 | 人脸识别+定位双重验证 |
| 数据统计 | 人工汇总 | AI 预测+可视化大屏 |
| 预警机制 | 被动响应 | 主动风险预测 |
| 交互方式 | 表格+表单 | 自然语言问答 + 智能助手 |
| 代码质量 | 单体 ~4445 行 | 模块化 11 个独立文件 |

## 🧩 模块化设计

### 重构成果
单体 `server.js`（~4445 行）已成功重构为 **11 个独立模块**，总代码量从 ~4700 行降至 ~2233 行（去除注释和空行）。

| 文件 | 行数 | 职责 |
|------|------|------|
| `server.js` | 424 | 主入口：初始化、中间件、路由挂载、WebSocket |
| `routes/auth.js` | 156 | 登录、用户管理、密码修改 |
| `routes/students.js` | 181 | 学生 CRUD、Excel 导入导出 |
| `routes/checkin.js` | 333 | 查寝签到、请假、课堂签到、学生认证 |
| `routes/statistics.js` | 117 | 基础统计分析 |
| `routes/advanced-stats.js` | 81 | 操行评分、宿舍排名 |
| `routes/dashboard.js` | 143 | 大屏公开 API |
| `routes/ai.js` | 292 | AI 预测、人脸识别、学工助手 |
| `routes/system.js` | 262 | 系统管理：日志、备份、数据清理 |
| `middleware/auth.js` | 163 | JWT 认证、角色权限、登录限流 |
| `utils/helpers.js` | 81 | 辅助函数 |

### 设计模式
- **工厂函数模式**: 每个路由模块导出 `init()` 函数，接收依赖注入对象
- **依赖注入**: `init({ db, scheduleSave, authMiddleware, ... })` 传递共享资源
- **统一接口**: 所有模块遵循相同的初始化模式，易于维护和扩展

## 🤖 AI 功能亮点

### 1. 人脸识别签到

#### 工作原理
1. **人脸注册**: 教师上传学生照片 → 自动提取 128 维人脸特征向量
2. **签到验证**: 学生拍照 → 提取人脸特征 → 与注册特征比对（余弦相似度 ≥0.65）
3. **双重保障**: 人脸识别 + GPS 定位 + 时间戳

#### 技术细节
- 使用 `face-api.js` 进行人脸检测和特征提取
- 128 维 Face Descriptor（人脸特征向量）
- 余弦相似度计算匹配度
- 支持本地模型和 CDN 两种加载方式

#### 使用流程
```
教师端: 🤖 人脸管理 → 选择学生 → 拍照/上传 → 确认注册
学生端: 签到 → 自动拍照 → 提取人脸特征 → 上传验证
大屏展示: 实时显示已注册人脸比例
```

### 2. 数据预测功能

#### 签到率趋势预测
- **分析方法**: 线性回归（Linear Regression）
- **数据基础**: 过去 30 天签到记录
- **预测周期**: 未来 7 天
- **可视化**: Chart.js 折线图（历史+预测对比）

#### 风险学生预警
- **评分算法**: 缺勤次数×5 + 连续缺勤加分
- **数据来源**: 过去 14 天未归记录
- **输出**: 风险排名前 10 的学生

#### 请假趋势预测
- **分析方法**: 按月统计 + 线性回归
- **预测周期**: 未来 3 个月
- **分类统计**: 事假/病假/实习

### 3. 智能学工助手

#### 功能
- 实时数据查询
- 自然语言交互
- 快捷问题按钮
- 班级/学生统计

#### 支持查询
| 查询类型 | 示例 |
|---------|------|
| 学生人数 | "今天有多少学生？" |
| 签到统计 | "今天签到情况如何？" |
| 请假分析 | "请假情况怎样？" |
| 班级分布 | "各班级人数分布" |

## 🖥️ 部署指南

## ❓ 常见问题

### 1. 人脸识别为什么没反应？
- 确保已为学生注册人脸特征
- 检查网络是否可访问 face-api.js CDN
- 摄像头权限是否已授权

### 2. 数据预测准确吗？
- 当前使用线性回归，适合短期预测
- 数据越多越准确（建议至少 30 天记录）
- 长期预测建议接入 ML 模型

### 3. 如何备份数据？
- 教师端 → 数据管理 → 创建备份
- 自动备份每天凌晨执行
- 备份文件在 `backups/` 目录

### 4. 忘记密码怎么办？
- 直接修改数据库中的 password_hash
- 或使用 Super Admin 重置密码

### 5. 模块化重构会影响功能吗？
- 完全不会影响！重构仅涉及代码组织结构
- 所有 API 接口保持向后兼容
- 功能无任何变化
